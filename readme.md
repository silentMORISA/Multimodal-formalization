# Datasets
1. UniGeo
- Website: https://github.com/chen-judge/UniGeo
- Details: contains 4,998 calculation problems and 9,543 proving problems.

2. Geometry3K
- Website: https://lupantech.github.io/inter-gps/
- Details:consisting of 3,002 geometry choice problems with dense annotation in formal language.

3. PGPS9K
- Website: https://huggingface.co/datasets/PeijieWang/PGPS9K
- Details: PGPS9K is composed of 9,022 geometry problems paired with non-duplicate 4,000 geometry diagrams, where 2,891 problems paired with 1,738 diagrams are selected from Geometry3K dataset, the rest of problems are collected from five popular textbooks across grades 6-12 on mathematics curriculum websites.
